# Консольное приложение калькулятор + конвертер
Программа умеет считать арифметические выражения и переводить единицы измерения
# Команды:
- python -m toolkit calc "EXPRESSION"
  1) Вычисление выражения
  2) Доступные операции: + - * / % // ( )
  3) Производится токенизация и перевод в обратную польскую запись
- python -m toolkit convert VALUE --from UNIT --to UNIT
  1) Конвертация различных единиц
  2) доступные величины: ['mm', 'cm', 'm', 'km'], ['kg', 'g'], ['k', 'c', 'f']
- python -m toolkit --help
